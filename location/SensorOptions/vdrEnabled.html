vdrEnabled property

bool vdrEnabled
getter/setter pair

Controls VDR (Vehicle Dead Reckoning) usage with GNSS and HD GNSS. If false, VDR is disabled. VDR is currently available on Android only. This feature is disabled by default: Contact us to enable it. Defaults to false.
