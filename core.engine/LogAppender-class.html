LogAppender

LogAppender class abstract

Implement this interface to receive log messages from the HERE SDK via LogControl.setAppender.

To receive log messages emitted during HERE SDK initialization, set the appender before creating the SDK engine. Setting it later still affects subsequent log messages. The level passed to LogControl.setAppender acts as the minimal threshold. Inside LogAppender.log, you can apply additional runtime filtering or reroute messages.
