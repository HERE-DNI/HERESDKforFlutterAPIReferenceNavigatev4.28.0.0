IndoorRouteStyle

IndoorRouteStyle class abstract

Represents a style of the indoor route.

Contains information about route colors, widths, and markers. Markers set through this style override the SDK's built-in defaults. Any marker left unset will automatically use the SDK's default icon when the route is rendered.
