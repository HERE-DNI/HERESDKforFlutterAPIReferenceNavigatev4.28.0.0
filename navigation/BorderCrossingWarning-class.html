BorderCrossingWarning class

A border crossing.

The main field describing the border crossing is BorderCrossingWarning.type specifying whether the border crossing is given for a country border or a state border. The BorderCrossingWarning.type must be known. The country and state codes are contained in BorderCrossingWarning.administrativeRules along with other information such as speed limits, u-turn regulations or pre-trip planning information contained by the AdministrativeRules.

Use BorderCrossingWarningListener to get notifications about upcoming country or state border crossings.
