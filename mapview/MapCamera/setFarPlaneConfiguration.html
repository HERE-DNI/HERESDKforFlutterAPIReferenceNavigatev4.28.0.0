Sets far plane distance configuration per zoom level.

Values are linearly interpolated between provided zoom levels.

For z between z0 and z1:

t = (z - z0) / (z1 - z0)
distanceFactor(z) = lerp(distanceFactor0, distanceFactor1, t)
minDistance(z) = lerp(minDistance0, minDistance1, t)

Effective far plane for the current frame is:

farPlaneInMeters = max(
    minDistance(z),
    distanceToTargetInMeters * distanceFactor(z)
)

Sample Configuration (balanced quality/performance, tune per zoom level):

  • 14.4 -> FarPlaneConfiguration(1.3)
  • 18.34 -> FarPlaneConfiguration(2.0)
  • 19.60 -> FarPlaneConfiguration(1.3)

MapCameraFarPlaneConfiguration.minDistanceInMeters remains default in this case.

Passing an empty map clears the per-zoom override and restores the default behavior.

Non-finite zoom levels or values are ignored. Distance factors are clamped to 0.1 to 10.0. The minimum distance is clamped to a range of [100, 3000] meters.

  • configs Per-zoom override mapping from zoom level to distance configuration.
