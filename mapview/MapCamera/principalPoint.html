principalPoint

principalPoint property

Point2D principalPoint

The pixel point where the target is placed within the map view. By default, the principal point is located at the center of the map view. It is set in pixels relative to the map view's origin top-left (0, 0).

The valid range for the principal point is: 0 <= x <= width and 0 <= y <= height, where width and height are the dimensions of the map view in pixels.

The value of the principal point is adjusted when the dimensions of the map view change, so that it stays in the same point relative to width and height. Meaning that when a principal point is set to bottom middle of the map view, it will stay in the bottom middle regardless of the changes to dimensions and orientation of the view.

Note: The principal point affects all programmatic map transformations (rotate, orbit, tilt and zoom) and the two-finger-pan gesture to tilt the map. Other gestures, like pinch-rotate, are not affected. Gets the pixel point that determines where the target is placed within the map view.
